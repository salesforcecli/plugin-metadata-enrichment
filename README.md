# plugin-metadata-enrichment

[![License](https://img.shields.io/badge/License-Apache--2.0-blue.svg)](https://opensource.org/license/apache-2-0)

> **⚠️ Deprecated and retired.** The `sf metadata enrich` CLI command and its npm package `@salesforce/plugin-metadata-enrichment` have been retired. Conversational and agent-assisted metadata enrichment is now served by the sanctioned portable Skill, which is the supported migration target. This repository no longer ships a CLI command and is no longer maintained.
